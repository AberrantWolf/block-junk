# KayKit RPG Tools Bits 1.0

Hand tools + work props. Shared texture `tools_bits_texture.png`
(imported). `anvil`, `axe`, `hammer`, `pickaxe` already in use. Two extra
map/blueprint textures ship in the pack (`tools_bits_map*.png`,
`tools_bits_blueprint.png`) for those specific meshes.

## Imported

`axe`✅, `hammer`✅, `pickaxe`✅ (items), `anvil`✅ (smithing station block).

## Available (curated)

**Tools that map to planned work verbs** — `saw`, `shovel`, `chisel`,
`mallet`, `handdrill`, `handplane`, `file`, `trowel`, `knife`, `scissors`,
`tongs`, `wrench_A/B`, `screwdriver_*`. Pair with the Tools rig clips
(`Sawing`, `Digging`, `Hammering`, …) for A1 held-tool animations.

**Crafting-station props** — `grindstone`, `bucket_metal`, `bucket` (also
in Dungeon), `anvil`✅.

**Fishing** (if fishing lands) — `fishing_rod`, `fishing_rod_base`,
`fishing_hook_A/B`, `fishing_floater`, `fishing_worm`,
`fishing_tacklebox`(`_empty`) + the Tools rig `Fishing_*` clip set.

**Lockpicking / access** — `key_A/B/C`, `lock_A/B/C`, `lockpick_*`,
`lockpick_set`, `keyring`(`_hanging`), `padlock` via `lock_*`.

**Survey / decor** — `map`(`_empty`,`_rolled`), `blueprint`(`_stacked`),
`journal_{open,closed}`, `compass_base`, `drafting_compass`,
`magnifying_glass`, `pencil_*`, `rope_bundle_A/B`, `nail`, `screw_A/B`,
`lantern` (no light system — decor), `torch`(`_burnt`).

Note this pack also has its own `pickaxe` (distinct from the one we use)
and Dungeon has a `pickaxe`/`pickaxe_gold` too — three pickaxe meshes
across packs; we use the RPG Tools one.
